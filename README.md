## Projects

### LifeLedger — Financial Simulation Platform

**Live Demo:** https://lifeledger-1.onrender.com/

**GitHub:** https://github.com/JotsaroopSinghh/LifeLedger

LifeLedger is a full-stack financial simulation web application that models long-term cash flow, debt, and investment performance.

- Implements Monte Carlo simulation for stochastic investment returns
- Estimates probability of insolvency and net-worth outcome distributions (p10 / median / p90)
- Backend built with Python + FastAPI
- Frontend built with React (Vite)
- Uses NumPy for numerical computation
- Deployed on Render
